
# 👁️ Advanced Computer Vision

This repository contains a structured collection of tutorials, articles, notebooks, and practical projects covering important topics in modern Computer Vision and Deep Learning.

This section focuses on advanced computer vision tasks, starting with object detection and semantic segmentation, then moving toward object tracking and modern Transformer-based vision architectures.

Each subfolder focuses on a specific computer vision task or architecture and combines theoretical concepts with practical implementations.

## 🔄 Computer Vision Workflow

The topics in this section cover several major levels of visual understanding:

**Image → Detection → Segmentation → Tracking → Transformer-Based Vision**

These tasks demonstrate how computer vision systems can progress from understanding individual images to detecting objects, predicting pixel-level information, tracking objects through time, and modeling global visual relationships using Transformer architectures.
