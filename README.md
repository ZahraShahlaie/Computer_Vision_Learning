# Computer Vision Learning

A structured learning repository covering **Image Processing, Computer Vision, and Deep Learning**, progressing from fundamental concepts to advanced computer vision techniques and practical projects.

The repository combines theoretical concepts with hands-on implementations using **Python, OpenCV, TensorFlow, Keras, and PyTorch**.

---

## 📚 Repository Structure

### 🖼️ 01 - Image Processing

Fundamentals of digital images and image processing with OpenCV.

Topics include:

* Image Structure & Types
* OpenCV Basics
* Bit Depth
* Transparency
* Data Types
* Contrast & Histograms
* HSV Color Space

---

### ✨ 02 - Image Enhancement

Classical image enhancement and feature extraction techniques.

Topics include:

* Brightness & Contrast
* Histogram Equalization & CLAHE
* Image Filtering & Noise Reduction
* Sharpening
* Edge Detection
* Hough Transform
* Parking Spot Detection

---

### 🧠 03 - Deep Learning in Computer Vision

Deep learning concepts and practical implementations for computer vision.

Topics include:

* Transfer Learning & Fine-Tuning
* Keras Functional API
* Custom CNNs
* Model Comparison & Evaluation
* PyTorch Basics
* Neural Network Training

---

### 👁️ 04 - Advanced Computer Vision

Advanced computer vision techniques, architectures, and real-world applications.

Topics include:

* Object Detection
* Semantic Segmentation
* Object Tracking
* Vision Transformers
* Real-Time Video Processing

Practical projects include:

* 🔬 **Colonoscopy Polyp Detection & Tracking** — YOLO11-based detection, tracking, and automatic frame capture.
* 🚗 **Road Lane Segmentation & Vehicle Tracking** — DeepLabV3+, YOLO11, and BoT-SORT for integrated road perception.

> **Note:** The medical project is for research and educational purposes only and is not a certified medical device or diagnostic system.
