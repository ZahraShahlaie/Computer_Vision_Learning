# 🎯 Object Detection with Deep Learning

This repository contains a structured collection of tutorials, articles, and notebooks covering the fundamental concepts and modern approaches of Object Detection in Computer Vision.

The section starts with the basic concepts of object detection, annotation formats, and evaluation metrics, then explores the evolution of object detection algorithms from two-stage detectors such as R-CNN family to single-stage detectors such as SSD and YOLO.

---

## 📚 Course Structure

### 01 - Introduction to Object Detection

Learn the fundamental concepts behind object detection and understand how it differs from image classification.

Topics include:

- What is Object Detection?
- Classification vs Localization vs Detection
- Bounding Boxes
- Object Classes
- Confidence Scores
- Object Detection Pipeline

---

### 02 - Annotation

Understand how datasets are prepared for object detection tasks.

Topics include:

- Annotation Concept
- Bounding Box Annotation
- Annotation Formats

### 03 - Object Detection Approaches

Explore the main categories of object detection algorithms.

Topics include:

- Traditional Computer Vision Approaches
- Region-Based Methods
- Two-Stage Detectors
- Single-Stage Detectors
- Advantages and Limitations of Each Approach

### 04 - Evaluation Metrics

Learn how object detection models are evaluated.

Topics include:

- True Positive, False Positive, False Negative
- Precision
- Recall
- Average Precision (AP)
- Mean Average Precision (mAP)

### 06 - Fast R-CNN

### 07 - Faster R-CNN

### 11 - YOLOv3
